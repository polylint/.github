# Security Policy

This policy applies to every repository in the [polylint](https://github.com/polylint) organization that does not
publish its own `SECURITY.md`.

## Supported Versions

Security fixes go into the latest release from the default branch.

## Reporting a Vulnerability

Please do not report a security vulnerability in a public issue. Instead, use GitHub's private vulnerability
reporting on the affected repository: open its **Security** tab and choose **Report a vulnerability**.

Include the affected version, steps to reproduce, the impact, and any fix you suggest.
