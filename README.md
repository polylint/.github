# polylint/.github

Organization-wide defaults for [github.com/polylint](https://github.com/polylint):

- `profile/README.md` is the organization profile.
- `profile/assets/` holds the brand assets: `logo.svg` (the stepped-tower mark), `avatar.svg` / `avatar.png` (the
  full-bleed avatar), and `banner.svg` / `banner.png`.
- `SECURITY.md` and `.github/FUNDING.yml` apply to every repository that does not define its own.

The palette is gold `#e0bb5e`, brass `#b48a3a`, light gold `#f8e7b0`, and navy `#070a13` / `#16213a`, shared with
the polylint banner.
